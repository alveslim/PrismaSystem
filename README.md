# Gerador de Ordens de Produção (OPs)

Este é um aplicativo desktop desenvolvido em Python utilizando a biblioteca **CustomTkinter** para a criação de uma interface gráfica (GUI) moderna. O sistema facilita o cadastro e o gerenciamento de Ordens de Produção (OPs), permitindo exportar os dados para formatos comuns e realizar impressões diretamente pelo sistema.

## 🚀 Funcionalidades

* **Interface Moderna:** Construída com CustomTkinter, adaptando-se automaticamente ao modo claro/escuro do sistema operacional.
* **Sugestão Automática de OP:** Integração com banco de dados para buscar e sugerir o próximo número de OP disponível.
* **Exportação de Dados:**
  * Salvar os dados estruturados em formato **CSV**.
  * Gerar relatórios formatados em **PDF**.
* **Impressão Direta:** Suporte nativo para envio de comandos de impressão (otimizado para ambientes Linux).
